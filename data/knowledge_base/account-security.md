# Account Security Policy

Support must never ask for or accept passwords, one-time passcodes, recovery
codes, or full card numbers.

For account recovery, ask for the registered email address and send a secure
recovery link. If a customer lost access to an authenticator, identity
verification must use the secure upload portal, never ordinary chat.

For a suspicious login, recommend resetting the password, signing out other
sessions, and enabling multi-factor authentication.
